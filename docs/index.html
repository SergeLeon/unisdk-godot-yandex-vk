UniSDK — Yandex Games & VK Games SDK for Godot 4

One GDScript API for the Russian web game platforms — Yandex Games, VK Games and OK Games: rewarded and interstitial ads, in-app purchases, leaderboards, cloud saves, review prompts, and ready-to-upload HTML5 export presets. Free and open source, MIT.

What UniSDK does

UniSDK is a Godot 4 editor plugin that hides the differences between the Yandex Games SDK (YaGames) and the VK Bridge. You export one HTML5 build, the platform adapter is detected at runtime from the JavaScript environment, and your game code talks to a single facade — UniSDK.ads, UniSDK.payments, UniSDK.leaderboards, UniSDK.storage.

Ads

Rewarded video, interstitial with cooldown, banners and native ads. Per-format state (supported / unknown / disabled), waiting limits, and a reason in every result.

Purchases

Catalog, purchase flow and unconsumed-payment recovery on top of the Yandex and VK payment APIs.

Leaderboards

Set scores and read entries; capability checks tell you up front whether the platform allows a full board.

Cloud saves

Yandex Player Data and VK Storage with a local cache, diff-based writes, retries and pause/resume on page visibility changes.

Editor mock mode

A mock bridge answers every call inside the editor and stores data in user://unisdk_mock_data.json, so the game runs without a platform account.

Export tooling

Generates web export presets, injects the required HTML shells (Yandex SDK / VK Bridge), patches the Emscripten browser check, adds cache-busting, zips the build.

Installation

  1. Install UniSDK from the Godot Asset Store (or copy addons/uni_sdk into your project).
  2. Open Project → Project Settings → Plugins and enable UniSDK.
  3. The UniSDK autoload registers itself; default platform profiles are created on first run.

Minimal usage

func _ready() -> void:
    await UniSDK.initialized
    UniSDK.ads.show_rewarded(func(result: Dictionary) -> void:
        if result.get("success", false):
            grant_coins()
    )

Requirements and limits

  • Godot 4.3 or newer; the addon targets the Web (HTML5) export.
  • Desktop and mobile builds fall back to the mock bridge — that is what makes editor testing possible.
  • Production ads, purchases and cloud saves need a published game and credentials from Yandex Games / VK Games. OK Games support goes through the same VK Bridge and is partial.

SDK для Яндекс.Игр и ВК Игр на Godot 4

UniSDK — плагин для Godot 4, который даёт единый GDScript API для Яндекс.Игр, ВК Игр и Одноклассников. Собираешь одну HTML5-сборку — адаптер платформы выбирается сам при запуске, а игровой код обращается к одному фасаду UniSDK.

Что внутри

  • Реклама: rewarded, interstitial с кулдауном, баннеры; состояние форматов, лимиты ожидания, причина отказа в результате показа.
  • Покупки: каталог, покупка, восстановление неиспользованных платежей.
  • Лидерборды: отправка очков и чтение таблицы, проверки доступности полной таблицы.
  • Облачные сохранения: Yandex Player Data и VK Storage с локальным кэшем, diff-записями, повторами и сохранением при сворачивании вкладки.
  • Отзывы и «в избранное»: запрос оценки и ярлык на добавление игры в закладки.
  • Mock-режим в редакторе: игра, сохранения и «показ рекламы» работают без аккаунта платформы.
  • Экспорт: диалог создаёт Web-пресеты, подставляет HTML-оболочки Яндекса и VK, правит проверку браузера в Emscripten, добавляет cache-busting и пакует ZIP.

Установка

Поставь плагин из Godot Asset Store либо скопируй папку addons/uni_sdk в проект, затем включи UniSDK в Project → Project Settings → Plugins.
